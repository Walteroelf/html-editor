# HTML-Editor

Kleiner HTML-Editor mit Live-Vorschau für den Unterricht: Code links einfügen oder schreiben, rechts sieht man sofort das Ergebnis. Eine einzige Seite (`index.html`), kein Build-Schritt, kein Konto, kein Server. Alles bleibt auf dem Gerät.

## Funktionen

- **Live-Vorschau** rechts neben dem Editor
- **Syntax-Highlighting** (Tags, Attribute, Werte, Kommentare) und **Zeilennummern**
- **Automatisches Merken** im Browser (`localStorage`): Code, Dateiname, Druckrand, Ausrichtung, Dunkelmodus und Trennerposition
- **Datei laden** über „Öffnen“ oder per Drag & Drop
- **Verschiebbarer Trenner** (Maus, Touch oder Pfeiltasten, Doppelklick = 50 %)
- **Dunkelmodus** (folgt zuerst der Geräteeinstellung, umschaltbar)
- **Speichern** als `.html`-Datei und **Drucken** (A4 hoch oder quer, Rand 10 bis 30 mm)

## Gestaltung

Wie die anderen Unterrichts-Apps am Erscheinungsbild der Spiele München 1972 (Otl Aicher) orientiert: helle, heitere Farben, flache Flächen, kleine Rundungen, kein Rot und kein Schwarz (Schrift in Dunkelblau). Leseschrift Andika (lokal, siehe `schriften/`).

## Benutzen

Auf GitHub Pages öffnen oder `index.html` lokal im Browser öffnen.
